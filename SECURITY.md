# Security

## Reporting a vulnerability in Unilaunch

If you have found a security issue in [unilaunch.online](https://unilaunch.online)
— anything that could expose users' funds, data or transactions — please report
it privately through [a support ticket](https://unilaunch.online/open-ticket)
rather than opening a public issue here. Include what you found, how to
reproduce it, and how you would like to be credited.

Please do not test against other people's wallets, tokens or positions.

## Reporting a problem with this handbook

Factual errors, dead links and outdated numbers can go straight into a public
issue in this repository — none of that is sensitive.

## Reporting impersonation

Fake "support" accounts appear around every crypto tool. If you are contacted
by someone claiming to be Unilaunch:

- Real support never messages first, and never uses DMs on any platform.
- Real support never asks for a seed phrase, a private key, or a wallet
  connection to an unfamiliar site.
- Everything legitimate happens inside a ticket you opened yourself, after
  connecting your wallet on the site.

Report impersonators to the platform they are using, and let the team know
through a ticket so other users can be warned.

## If your wallet is already compromised

Move remaining funds to a wallet created from a fresh seed phrase, revoke
outstanding token approvals, and treat the old wallet as permanently unsafe.
Confirmed blockchain transactions cannot be reversed by anyone. See
[Avoiding scams](docs/avoid-scams.md).
